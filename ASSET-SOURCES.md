# Technology and contact icon sources

The technology symbols in `assets/icons/` come from [Devicon](https://github.com/devicons/devicon) and [Simple Icons](https://github.com/simple-icons/simple-icons), downloaded October 24, 2026. The rounded tile backgrounds are custom. Brand colors and paths are preserved; the monochrome GitHub, Ollama and Solidity marks adapt to dark and light backgrounds, and the Hugging Face mark uses its yellow brand color.

Each icon has a self-contained `-dark.svg` and `-light.svg` version. Native size: 68 × 68. Recommended README display size: **52 × 52** (or 48 × 48 in a dense row). For the GitHub, LinkedIn, Gmail, and Portfolio contact row, use **40–44 × 40–44**. Each file includes a readable SVG title. Use GitHub's theme-aware `<picture>` pattern for the pairs.
